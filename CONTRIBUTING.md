# Contributing to KSA Helper

Thank you for your interest in contributing to KSA Helper.

KSA Helper is an open-source project focused on helping people in Saudi Arabia understand where to find the right official service for common everyday situations.

Contributions are welcome.

## Ways to Contribute

You can help by:

* Reporting bugs
* Suggesting new features
* Improving the user interface
* Improving Arabic translations
* Improving accessibility
* Adding common Saudi service situations
* Improving search functionality
* Improving documentation
* Verifying service information against official sources

## Before You Start

Please make sure that any information related to Saudi government services is verified using an appropriate official source.

Avoid adding information based only on assumptions, social media posts, or outdated third-party websites.

## Development Workflow

Create a new branch for your change.

Example:

```bash
git checkout -b feature/improve-search
```

Make your changes, then stage them:

```bash
git add .
```

Commit your changes:

```bash
git commit -m "feat: improve search"
```

Push your branch:

```bash
git push -u origin feature/improve-search
```

Then open a Pull Request on GitHub.

## Branch Naming

Use clear branch names.

Examples:

```text
feature/arabic-search
feature/new-problem-categories
fix/mobile-layout
fix/rtl-alignment
docs/update-readme
```

## Commit Messages

Use short and descriptive commit messages.

Examples:

```text
feat: add new problem category
fix: correct Arabic layout
docs: update contributing guide
style: improve mobile design
refactor: simplify problem data
```

## Privacy and Security

Do not add features that request or store unnecessary sensitive information.

KSA Helper should not collect:

* Iqama numbers
* Passport numbers
* Passwords
* OTP codes
* Banking credentials
* Government account credentials

The project should collect as little personal data as possible.

## Pull Requests

When creating a Pull Request:

* Explain what you changed
* Explain why the change is useful
* Include screenshots for UI changes where possible
* Test your changes before submitting
* Keep each Pull Request focused on one feature or fix

## Code Style

Keep the code:

* Simple
* Readable
* Well organized
* Mobile friendly
* Accessible
* Easy for other contributors to understand

## Questions and Suggestions

If you have an idea but are unsure how to implement it, open a GitHub Issue before starting.

This helps avoid duplicate work and allows the idea to be discussed first.

Thank you for helping improve KSA Helper.
